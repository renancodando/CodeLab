# Currículo do zero à especialização

## Critério editorial

Cada aula publicada precisa de explicação original, conceitos relacionados, código completo, rastreamento, erro diagnosticável, exercício com critérios, solução e projeto. Um título em um plano não conta como aula concluída. A cobertura da linguagem é diferente da cobertura de todas as bibliotecas de terceiros.

## Expansão em andamento

O catálogo original possui 60 aulas. A nova arquitetura mantém esse conteúdo e carrega os capítulos adicionais por linguagem ao abrir a aula. O build também gera páginas completas sem JavaScript e o catálogo da API existente.

Primeiro pacote escrito: Python, com seis módulos de fundamentos a engenharia. Próximos pacotes desta expansão: TypeScript, C++, HTML, CSS, JavaScript, C# e SQL. A matriz detalhada será gerada do conteúdo publicado ao concluir os oito pacotes.

## Validação

O CI verifica vínculos, unicidade, profundidade textual, exemplos JavaScript e fluxos de leitura. Exemplos das linguagens externas exigem seus compiladores/interpretadores; uma aula publicada não implica que o laboratório ofereça execução local dessas linguagens. TypeScript será apresentado como código para compilar com tsc, sem simular uma execução que o laboratório não suporta.
